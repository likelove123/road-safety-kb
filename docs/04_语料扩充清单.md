## 三、入库操作（管理员账号）

1. 登录管理员账号 → 左侧「知识管理」→「新建入库」
2. 上传 PDF / Word / TXT，或粘贴网页地址直接抓取正文
3. 填写元数据：文号、效力状态、生成日期、废止日期、来源 URL
4. 系统自动按 MD5 查重，重复内容直接拦截
5. 「保存到草稿箱」→「提交审核」→「审核通过并发布」
6. 发布时按**条**切块并写入向量库，AI 即可检索到；「废止」后仍保留条款供追溯

## 四、硬性要求

1. **按条切块，不按篇切块**：法规按「第X条」，标准按编号标题，案例按「一、二、三」小标题，系统已自动处理。
2. **每篇必须有文号、效力状态、来源 URL**，答辩时能说清出处。
3. **案例与处罚决定必须脱敏**：车牌 `粤Bxxxxx`、身份证 `430***********2345`、姓名 `李某`，系统入库与回答时均自动处理。
4. **扫描件先 OCR**，否则解析为空，系统会提示跳过。
