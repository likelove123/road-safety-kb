# 道路运输安全 AI 知识库 — 选题定义

> 今天必须填完。填不完，后面 13 天都在空转。
> 每完成一项，把 `[ ]` 改成 `[x]`。

## 1. 一句话定义

面向 ______（使用者是谁），提供 ______（解决什么需求）的问答，
答案必须能追溯到 ______（哪一类依据）。

参考写法：面向运输企业安全员，提供安全生产制度与操作规程的问答，答案必须能追溯到现行有效法规的具体条款号。

## 2. 系统回答哪三类问题

1. 制度查询：______
2. 操作规范：______
3. 事故案例类比：______

## 3. 交付形态（双端）

- 本地：浏览器打开 http://localhost:8501
- 公网：一个别人能打开的 URL

## 4. 第 14 天验收标准

- [ ] 20 个测试问题中，≥16 个答案正确且引用条款正确
- [ ] 本地可访问，能连续问 5 个问题不崩
- [ ] 公网可访问
- [ ] 有"开启/关闭混合检索"的对比数据（论文实验章要用）

## 5. 明确不做的事（防止发散）

- 不做用户注册与权限管理
- 不做手机端适配
- 不做模型微调训练
- 不追求语料全覆盖，只覆盖第 2 节定义的三类问题
- 不做多轮复杂对话，先做好"一问一答 + 出处"
